# ICRA 2026 Paper List

A searchable, unofficial index of **2,951 paper entries** from the ICRA 2026 technical program, with **1,655 matched arXiv PDF links**.

Maintained by [Studeas](https://github.com/Studeas).

## Open the list

Download [index.html](index.html) using GitHub's **Download raw file** button, then open it in your browser. Everything needed to display and search the list is embedded in this one file. Internet access is required only to open external links.

- Search paper titles, authors and official keywords.
- Filter by session type; show all papers or use pagination.
- Switch between light and dark themes.
- Export all matching results as CSV, independently of pagination.
- Blue **pdf ↗** labels open arXiv PDFs; **-** indicates no confirmed arXiv match.

## Web display

For a public-facing paper list, use **GitHub Pages**. The repository file viewer displays HTML source rather than the interactive page.

After making the repository public, open **Settings → Pages**, choose **Deploy from a branch**, select **main / (root)**, and save. No build tools or dependencies are needed. The expected site address after deployment is `https://studeas.github.io/icra-2026-paper-list/`.

## Scope and maintenance

This index covers the official technical program, including journal presentations, award sessions and late-breaking results. It is not a proceedings acceptance count and does not include independently hosted workshop papers. The **5,088 submissions** statistic comes from the [official submission announcement](https://2026.ieee-icra.org/contribute/call-for-icra-2026-papers-now-accepting-submissions/).

arXiv matches were checked against titles and authors; title variants also required closely matching abstracts. Linked preprints can differ from the published version. Gray placeholders do not imply that no public version exists.

Snapshot verified: **2026-09-06 UTC**. Updates are maintained manually; the page does not run a crawler or update itself. To publish a new snapshot, replace `index.html` and commit the change. Corrections and verified arXiv links can be submitted through issues or pull requests.

Sources: [ICRA 2026 official program](https://ras.papercept.net/conferences/conferences/ICRA26/program/), [arXiv](https://arxiv.org/); candidate identifiers were seeded from the [ai-conferences/ICRA2026 dataset](https://huggingface.co/datasets/ai-conferences/ICRA2026) and checked against primary arXiv metadata.
